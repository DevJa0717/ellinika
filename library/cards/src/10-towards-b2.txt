# verb-objects | B1 | Τι ακολουθεί το ρήμα | What follows the verb

| Pattern | Verbs | Example |
|-|-|-|
| + accusative (no preposition) | περιμένω, ψάχνω, κοιτάζω, ακούω, ζητάω, πληρώνω, βοηθάω, ρωτάω, εμπιστεύομαι, φοβάμαι | Σε περιμένω. Τον βοήθησα. |
| + σε (pronoun: genitive) | απαντάω, τηλεφωνώ, ανήκω, συμμετέχω, χρωστάω, οφείλεται | Της απάντησα. Του χρωστάω. |
| + από | εξαρτάται, αποτελείται, παραιτούμαι | Εξαρτάται από σένα. |
| + με (pronoun: μαζί + genitive) | συμφωνώ, ασχολούμαι, τσακώνομαι, γελάω, μοιάζω | Συμφωνώ μαζί σου. |
| + για | ενδιαφέρομαι, μιλάω, ανησυχώ, ντρέπομαι | Ανησυχώ για σένα. |
| two accusatives | ρωτάω, κερνάω, χρεώνω | Σε κερνάω έναν καφέ. |
| linking verb + nominative | είμαι, γίνομαι, φαίνομαι, μένω, θεωρούμαι | Έγινε γιατρός. |
| object + accusative description | κάνω, θεωρώ, λέω, βρίσκω | Τον θεωρώ έξυπνο. |

- **Genitive of the person affected**: **Μου έκλεψαν το κινητό. Μου χάλασε το αυτοκίνητο.**
- **Two weak pronouns**: genitive first: **Θα σου το φέρω.**
- **Verb + noun pairs**: κάνω λάθος / υπομονή / πλάκα, παίρνω απόφαση / μέρος, δίνω σημασία / εξετάσεις, ρίχνω μια ματιά.

# spelling | A2 | Ορθογραφία και στίξη | Spelling and punctuation

| Sound-alike | Meaning |
|-|-|
| πώς / πως | how? / that |
| πού / που | where? / who, which, that |
| ή / η / οι | or / the (f. sg) / the (pl) |
| ό,τι / ότι | whatever / that |
| πια / πιο | any more / more |

| Ending | Spelling |
|-|-|
| verb 3sg / 2sg | -ει / -εις: θα λύσει, γράφεις |
| feminine noun | -η: η λύση |
| masculine plural | -οι: οι καλοί φίλοι |
| -μαι 3sg / 2pl | -εται / -εστε |
| passive aorist | -ηκα / -θηκα |

- **No stress mark** on one-syllable words (except ή, πού, πώς) or on words in capitals.
- **Diaeresis** splits a pair: προϊόν, κοροϊδεύω, Μαΐου; not needed after a stressed first vowel: τσάι, ρολόι.
- **;** is the question mark, **·** the semicolon, **« »** quotes. No comma before ότι, να, identifying που.
- Capitals for days, months, feasts and nationalities; lower case for languages: **τη Δευτέρα, ο Έλληνας, μιλάω ελληνικά**.

# register | B2 | Γραπτός λόγος | Formal written Greek

| Everyday | Formal |
|-|-|
| γιατί | διότι, καθώς |
| για να | προκειμένου να |
| αν / μέχρι | εάν, εφόσον / έως |
| παίρνω / δίνω / βάζω | λαμβάνω / παρέχω / θέτω |
| κάνω (έρευνα) | πραγματοποιώ, διεξάγω |
| Λένε ότι... | Λέγεται ότι... / Εκτιμάται ότι... |
| Αυξήθηκαν οι τιμές. | η αύξηση των τιμών |

- **Internal augment** under stress: υπογράφω → υπέγραψα (but υπογράψαμε), συμβαίνει → συνέβη, επιστρέφω → επέστρεψα.

- **News forms**: εξελέγη, συνελήφθη, ελήφθη, διεξήχθη.
- **Fixed phrases**: εν λόγω, εν μέρει, εκ των προτέρων, εκ των υστέρων, κατά κανόνα, ως εκ τούτου.

# correlatives | B1 | Ο πίνακας των αντωνυμιών | Who, where, when: the correlative table

| | Person / thing | Place | Time | Manner |
|-|-|-|-|-|
| question | ποιος; τι; πόσος; | πού; | πότε; | πώς; |
| some- | κάποιος, κάτι | κάπου | κάποτε | κάπως |
| any- / no- | κανείς (κανένας), τίποτα | πουθενά | ποτέ | καθόλου |
| this / that | αυτός, εκείνος | εδώ, εκεί | τώρα, τότε | έτσι |
| relative | που, ο οποίος | όπου | όταν | όπως, καθώς |
| -ever | όποιος, ό,τι, όσος | όπου | όποτε | όπως |
| any at all | οποιοσδήποτε, οτιδήποτε | οπουδήποτε | οποτεδήποτε | οπωσδήποτε |
| every- | καθένας, καθετί, όλοι | παντού | πάντα | |
| else | άλλος, άλλο | αλλού | άλλοτε | αλλιώς |

- **Κανείς, τίποτα, πουθενά, ποτέ, καθόλου** mean "no-" with **δεν** (**Δεν ήρθε κανείς**) and "any-" in questions and conditions (**Ήρθε κανείς;**).
- **Τόσος... όσος**, **τέτοιος** "such": **Δεν έχω τόσα λεφτά όσα νομίζεις. Τέτοιο καιρό δεν έχω ξαναδεί.**
- **Οπωσδήποτε** on its own means "definitely": **Θα έρθω οπωσδήποτε.** **Πάντως** means "anyway, in any case". **Οπότε** (stress on the last syllable) means "so"; **όποτε** means "whenever".

@ theoria.indefinites, theoria.relatives, cards.determiners
