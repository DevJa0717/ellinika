# word-order | B1 | Σειρά των λέξεων | Word order, topic and focus

| Order | Example | Message |
|-|-|-|
| SVO | Ο Νίκος έφερε το κρασί. | neutral |
| VSO / VS | Έφερε ο Νίκος το κρασί. Ήρθε ο Νίκος. | neutral; the event is news |
| O + clitic + V S | Το κρασί το έφερε ο Νίκος. | the wine = topic; Nikos = new |
| O (stressed) V S | ΤΟ ΚΡΑΣΙ έφερε ο Νίκος. | the wine = contrastive focus |
| clitic V ... O | Το έφερες το κρασί; | spoken afterthought |

- **Fronted object + doubling pronoun = topic** (already known). **Fronted object without pronoun = focus** (new, contrasted). Indefinites (**κάτι, τίποτα, ένα ...**) fronted are focus and take no pronoun.
- **Subject pronouns** only for contrast: **Εγώ πληρώνω.**
- **Questions**: question word first, then verb, then subject: **Πού μένει η Μαρία;** A preposition goes with its question word: **Με ποιον μίλησες;**
- **Noun phrase**: article + adjective + noun (**το μεγάλο σπίτι**); emphatic **το σπίτι το μεγάλο**; possessive after noun or first adjective (**το καινούργιο μου σπίτι**); demonstrative + article (**αυτό το σπίτι**).
- **Writing**: given before new, heavy elements last; headlines verb-first: **Ψηφίστηκε το νομοσχέδιο.**

# clitics | B1 | Θέση των αδύνατων τύπων | Where weak pronouns go

| Verb form | Position | Example |
|-|-|-|
| indicative, subjunctive, future, perfect | before the verb | Τον είδα. Θα σου πω. Να το κάνεις. Το έχω δει. |
| with δεν / μην / θα / να / ας | after them, before the verb | Δεν το ξέρω. Μην το πεις. Ας το αφήσουμε. |
| imperative | after the verb | Πες μου. Δώσ' το. Ρώτησέ τον. |
| gerund | after the verb | Βλέποντάς τον, ... |
| two pronouns | genitive, then accusative | Μου το είπε. Δώσε μού το. |
| verb chains | with their own verb | Θέλω να το δω. Μπορείς να μου το δώσεις; |

- **Extra accent**: stress on 3rd-from-last + pronoun → **διάβασέ το, το αυτοκίνητό μου**; stress on 2nd-from-last + two pronouns → **φέρε μού τα**.
- **Doubling**: a fronted or strong object repeats as a weak pronoun: **Τον Γιάννη τον ξέρω. Εμένα με ξέχασες. Στη Μαρία της αρέσει.**
- Never two accusative weak pronouns together; never a weak pronoun after an ordinary verb (that is Cypriot: **Είδα τον**).

# negation | A2 | Άρνηση | Negation

| Word | With | Example |
|-|-|-|
| δεν | indicative, θα | Δεν ξέρω. Δεν θα έρθω. |
| μη(ν) | να, ας, για να, prohibitions, participles | Να μην αργήσεις. Μη φύγεις! οι μη καπνίζοντες |
| όχι | answers; single words | Όχι. Θέλω τσάι, όχι καφέ. |
| ούτε | nor; not even | Ούτε εγώ. Ούτε καν ευχαριστώ. |
| ούτε ... ούτε | neither ... nor | Ούτε ψηλός ούτε κοντός. |

| Negative word | + δεν | In questions / conditions |
|-|-|-|
| κανείς, καμία, κανένα | Δεν ήρθε κανείς. | anyone: Ήρθε κανείς; |
| τίποτα | Δεν θέλω τίποτα. | anything: Θέλεις τίποτα; |
| ποτέ | Δεν πάω ποτέ. | ever: Έχεις πάει ποτέ; |
| πουθενά | Δεν το βρίσκω πουθενά. | anywhere |
| καθόλου | Δεν μου αρέσει καθόλου. | at all |

- **Two negatives make one**: **Κανείς δεν ξέρει τίποτα.**
- **Fear**: **Φοβάμαι μη(ν) + subjunctive** = "I'm afraid it may happen": **Φοβάμαι μην αργήσουμε.**
- **Δεν ... παρά** "only": **Δεν έχω παρά δέκα ευρώ.**

# mood | B1 | Ότι, να, που, αν | Which "that"?

| Word | Introduces | After | Example |
|-|-|-|-|
| ότι / πως | a statement, belief | λέω, νομίζω, ξέρω, πιστεύω, ακούω (news) | Νομίζω ότι έχεις δίκιο. |
| να | a wish, order, ability, possibility | θέλω, μπορώ, πρέπει, ελπίζω, λέω (tell to) | Θέλω να έρθεις. Του είπα να περιμένει. |
| που | the cause of a feeling; a perceived action | χαίρομαι, λυπάμαι, μετανιώνω; βλέπω | Χαίρομαι που ήρθες. Τον είδα που έφευγε. |
| αν / μήπως | an open question | ρωτάω, δεν ξέρω, αναρωτιέμαι | Δεν ξέρω αν θα έρθει. |
| μη(ν) | a feared possibility | φοβάμαι, ανησυχώ | Φοβάμαι μη χαθούμε. |
| το ότι / το να / το αν | a clause as a noun | prepositions; subject position | Παρά το ότι ήταν αργά, ... |

| Verb | + ότι | + να |
|-|-|-|
| ξέρω | know that | know how to |
| θυμάμαι | remember that | remember to |
| λέω | say that | tell (sb) to; be thinking of |
| αρνούμαι | deny that | refuse to |
| φοβάμαι | fear that | be afraid to |

- **ότι / πως / που** cannot be dropped like English "that".
- After **να** the verb is subjunctive; choose the stem by aspect: **Θέλω να σου γράψω / να μου γράφεις.**

@ b1-complement, syntax.complements, syntax.subjunctive

# na-chains | B1 | Αλυσίδες με το να | να-chains and the subjunctive

| Pattern | Example |
|-|-|
| same subject | Θέλω να φύγω. |
| different subject | Θέλω να φύγεις. Του είπα να φύγει. |
| chain | Θέλω να αρχίσω να μαθαίνω να παίζω κιθάρα. |
| with pronouns | Πρέπει να σου το πω. |
| purpose | Ήρθα για να σε δω. Πήγα να τον δω. |
| wish / suggestion | Να είσαι καλά! Να ανοίξω το παράθυρο; |
| "let" | Ας φύγουμε. |
| deduction about the past | Πρέπει να έφυγε. Μπορεί να το ξέχασε. |
| unreal wish | Μακάρι να ήμουν εκεί. Να το ήξερα! |

- No infinitive: the person shows in the ending, so "I want you to go" is **Θέλω να πας**, never *Θέλω εσένα να πας*.
- **After αρχίζω, συνεχίζω, σταματάω**: imperfective (**άρχισε να βρέχει**).
- **πρέπει** never changes person: **πρέπει να πάω / να πάμε**; past **έπρεπε**.
- **να + past** is not future: **Πρέπει να έφυγε** "(s)he must have left".

# clauses | B1 | Χρόνος, αιτία, σκοπός, αποτέλεσμα, εναντίωση | Time, cause, purpose, result, concession

| Type | Conjunctions | Verb |
|-|-|-|
| time (future) | όταν, μόλις, αφού, πριν (να), μέχρι να | perfective non-past, **no θα**: όταν έρθεις |
| time (past, habit) | όταν, μόλις, ενώ, καθώς, όσο | indicative: όταν ήρθε, ενώ έτρωγε |
| cause | επειδή, γιατί, αφού, καθώς, μια και, διότι | indicative |
| cause (noun) | λόγω, εξαιτίας + genitive | λόγω της απεργίας |
| purpose | για να, να, ώστε να, προκειμένου να | subjunctive |
| result (real) | τόσο ... που / ώστε, γι' αυτό, οπότε | indicative |
| result (news style) | με αποτέλεσμα να | subjunctive |
| concession (fact) | αν και, παρόλο που, μολονότι, ενώ | indicative |
| concession (possibility) | ακόμα κι αν, και να, όσο κι αν | subjunctive |
| concession (noun) | παρά + accusative | παρά τη βροχή |
| manner | όπως; σαν να | indicative |

- **Πριν (να)** takes the subjunctive form even about the past: **Πριν φύγει, πλήρωσε.**
- **Αφού** = "after" (time) or "since" (known cause): **Αφού φάμε, θα βγούμε. Αφού το ξέρεις, γιατί ρωτάς;**
- Spelling: **παρόλο που** (conjunction), **παρ' όλα αυτά** (nevertheless).

# conditionals | B1 | Υποθετικοί λόγοι | Conditionals

| Type | If-clause | Result | Example |
|-|-|-|-|
| real now | αν + present | present / imperative | Αν πεινάς, φάε. |
| future | αν + perfective non-past | θα + perfective | Αν βρέξει, θα μείνουμε μέσα. |
| real past | αν + past | any | Αν το είπε, έκανε λάθος. |
| unreal now | αν + imperfect | θα + imperfect | Αν είχα χρόνο, θα ερχόμουν. |
| unreal past | αν + pluperfect | θα + pluperfect | Αν το είχα ξέρει, θα σου το είχα πει. |
| mixed | αν + pluperfect | θα + imperfect | Αν είχα σπουδάσει, τώρα θα ήμουν γιατρός. |

| Other "if" words | |
|-|-|
| άμα (spoken), εάν (formal) | if |
| εκτός αν | unless |
| αρκεί να, φτάνει να | provided that |
| σε περίπτωση που | in case |
| με την προϋπόθεση ότι / να | on condition that |
| ακόμα κι αν, και να | even if |
| να + imperfect | had I ... / if only (Να το ήξερα!) |

- **No θα after αν**: *Αν θα έρθεις* → **Αν έρθεις**.
- In speech, **imperfect + θα + imperfect** also covers the unreal past: **Αν το ήξερα, θα σου το έλεγα.**

# reported | B2 | Πλάγιος λόγος | Reported speech

| Direct | Reported | Rule |
|-|-|-|
| «Είμαι κουρασμένος.» | Είπε ότι είναι κουρασμένος. | ότι/πως; keep the tense |
| «Θα έρθω.» | Είπε ότι θα έρθει. | θα stays (θα ερχόταν: doubt) |
| «Πού μένεις;» | Με ρώτησε πού μένω. | question word, statement order |
| «Θα έρθεις;» | Με ρώτησε αν θα πάω. | αν (μήπως) |
| «Περίμενε!» | Μου είπε να περιμένω. | να + subjunctive |
| «Μην αργήσεις!» | Μου είπε να μην αργήσω. | να μη(ν) |
| «Πάμε σινεμά;» | Πρότεινε να πάμε σινεμά. | προτείνω να |

| Shift (later, elsewhere) | |
|-|-|
| εδώ → εκεί | τώρα → τότε |
| σήμερα → εκείνη τη μέρα | αύριο → την επόμενη μέρα |
| χθες → την προηγούμενη μέρα | έρχομαι → πηγαίνω |

- Reporting verbs: **δηλώνω, ισχυρίζομαι, παραδέχομαι ότι; αρνούμαι ότι / να; υπενθυμίζω, προειδοποιώ, ζητάω, συμβουλεύω να**.
- News: **σύμφωνα με, όπως δήλωσε, φέρεται να, λέγεται ότι**. Speech: **..., λέει, ...** (hearsay).

# questions | A1 | Ερωτήσεις | Questions

| Type | How | Example |
|-|-|-|
| yes/no | same order, rising voice, ; | Είσαι έτοιμος; |
| question word | word first, then verb, then subject | Πού μένει η Ελένη; |
| with preposition | preposition + question word first | Με ποιον; Από πού; Για τι; |
| choice | ή | Τσάι ή καφέ; |
| tag | ε; έτσι δεν είναι; σωστά; | Ωραία, ε; |
| polite / cautious | μήπως | Μήπως ξέρετε πού είναι; |
| wondering | άραγε | Θα έρθει άραγε; |
| what should I ...? | τι / πού / πώς + να | Τι να κάνω; |
| indirect | αν / question word | Δεν ξέρω αν / πού ... |

| Question words | |
|-|-|
| τι, ποιος (declines), πόσος (declines) | what, who/which, how much |
| πού, πότε, πώς, γιατί | where, when, how, why |
| τίνος / ποιανού | whose |

- Exclamations: **Τι ωραία! Τι ωραίο σπίτι! Πόσο μεγάλωσες! Τι καλά που ήρθες!**
- **Πού / πώς** (questions) carry an accent; **που / πως** (that) do not.

# agreement | A2 | Συμφωνία | Agreement

| What | Agrees with | In | Example |
|-|-|-|-|
| verb | subject | person, number | Τα παιδιά παίζουν. Εσύ κι εγώ πάμε. |
| adjective, article | noun | gender, number, case | της καλής φίλης |
| predicate after είμαι | subject | gender, number; nominative | Η Ελένη είναι κουρασμένη. |
| predicate of an object | object | accusative | Τον θεωρώ έξυπνο. |
| ο οποίος | its noun | gender, number (case from its role) | η πόλη στην οποία ... |
| αρέσει, λείπει | the thing liked / missed | number | Μου αρέσουν τα σύκα. Μου λείπεις. |

- **Neuter plurals** take a plural verb: **Τα σπίτια είναι παλιά.**
- **Polite εσείς**: plural verb, singular adjective for one person: **Είστε κουρασμένη, κυρία Ελένη;**
- **Professions** after είμαι: no article: **Είναι δασκάλα.**
- **Two subjects** with εγώ → "we": **Ο Νίκος κι εγώ μένουμε εδώ.**

# discourse | B2 | Σύνδεση και οργάνωση του λόγου | Linking a text

| Function | Everyday | Formal |
|-|-|-|
| adding | και, επίσης | επιπλέον, επιπροσθέτως, εξάλλου |
| contrast | αλλά, όμως | ωστόσο, εντούτοις, αντίθετα |
| cause | γιατί, επειδή | διότι, καθώς, δεδομένου ότι |
| result | γι' αυτό, οπότε, άρα | επομένως, συνεπώς, κατά συνέπεια |
| example | για παράδειγμα | λόγου χάρη (λ.χ.) |
| clarifying | δηλαδή | με άλλα λόγια |
| sequence | πρώτα, μετά, στο τέλος | αρχικά, στη συνέχεια, τέλος |
| conclusion | τέλος πάντων | εν κατακλείδι, συνοψίζοντας |

| Speech particle | |
|-|-|
| λοιπόν | so, well |
| δηλαδή | that is; so? |
| βέβαια | of course; admittedly |
| πάντως | anyway |
| άλλωστε | besides, after all |
| τελικά | in the end |
| ίσα ίσα | on the contrary |

- **Paragraph**: θεματική περίοδος (topic sentence) → λεπτομέρειες (support) → κατακλείδα (closing).
- **Reference**: same subject → no pronoun; switch → **αυτός**; formal "the latter" → **ο τελευταίος**; sum up → **το φαινόμενο αυτό**.
- **Emphasis**: **ακόμα και, μάλιστα, κι όμως, αυτό που ... είναι, όσο για**.
