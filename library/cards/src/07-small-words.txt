# prepositions | A2 | Προθέσεις | Prepositions

| Preposition | Meanings | Example |
|-|-|-|
| σε (στο, στη ...) | in, at, to, on | στο σπίτι, στην Αθήνα, στις πέντε |
| από | from, by, since, than, through | από την Κρήτη, από το πρωί, από το παράθυρο |
| με | with, by (means) | με τον Νίκο, με το λεωφορείο |
| για | for, about, to (destination) | για σένα, για την Πάτρα, μιλάμε για πολιτική |
| χωρίς | without | χωρίς ζάχαρη |
| μέχρι / ως | until, as far as | μέχρι την Παρασκευή, ως το σπίτι |
| προς | towards | προς τη θάλασσα |
| κατά | during, about, against, according to | κατά τη διάρκεια, κατά τις οκτώ, κατά τον νόμο |
| παρά | despite; to (time) | παρά τον καιρό, πέντε παρά δέκα |
| μετά / πριν | after / before (with από) | μετά το φαγητό, πριν από την ταινία |
| αντί για | instead of | αντί για καφέ |
| σαν | like | σαν τον πατέρα του |

| Compound (adverb + σε / από) | |
|-|-|
| πάνω σε / πάνω από | on / above |
| κάτω από | under |
| μέσα σε / έξω από | inside / outside |
| μπροστά σε, μπροστά από / πίσω από | in front of / behind |
| δίπλα σε, κοντά σε / μακριά από | next to, near / far from |
| απέναντι από, ανάμεσα σε | opposite, between |

- All everyday prepositions take the **accusative**. Formal ones take the **genitive**: **λόγω, εξαιτίας, εναντίον, μεταξύ, εκτός, εντός, υπέρ, κατά τη διάρκεια, εις βάρος**.
- **Strong pronouns** follow prepositions: **για μένα, με σένα, από αυτόν, σ' εσάς**.

# particles | A2 | Μόρια | Particles: θα, να, ας, δεν, μη

| Particle | Job | Example |
|-|-|-|
| θα | future; probability; "would" | Θα έρθω. Θα είναι εκεί. Θα ήθελα ... |
| να | subjunctive; wishes; "shall I?" | Θέλω να φύγω. Να είσαι καλά! Να ανοίξω; |
| να (deictic) | "here is, there is" | Να ο Νίκος! Να τος! |
| ας | "let" | Ας φύγουμε. Ας έρθει. |
| δε(ν) | negates the indicative and θα | Δεν ξέρω. Δεν θα πάω. |
| μη(ν) | negates να, ας, prohibitions, participles | Να μην αργήσεις. Μην το πεις. |
| όχι | no; not (single words) | Όχι τώρα. Τσάι, όχι καφέ. |
| μήπως | perhaps, by any chance | Μήπως ξέρετε; |
| άραγε | I wonder | Τι να κάνει άραγε; |
| μάλλον, ίσως | probably, maybe | Μάλλον θα βρέξει. |

- **Order before the verb**: **δεν / μην → θα / να → weak pronouns → verb**: **Δεν θα σου το πω. Να μην του το πεις.**
- **Final ν** of **δεν, μην** stays before vowels and κ, π, τ, ξ, ψ, γκ, μπ, ντ, τσ, τζ (**μην αργήσεις, μην το πεις, μη φύγεις**); writing **δεν** everywhere is also accepted.
- Talking particles: **λοιπόν, δηλαδή, βέβαια, πάντως, άλλωστε, καλά, ε, ρε, μωρέ** (see the discourse card).

@ b2-particles, pos.particle~0, pos.particle~1, pos.particle~4, cards.negation, cards.discourse
