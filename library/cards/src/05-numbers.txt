# cardinals | A1 | Απόλυτα αριθμητικά | Counting

| | | | |
|-|-|-|-|
| 0 μηδέν | 10 δέκα | 20 είκοσι | 100 εκατό |
| 1 ένα | 11 έντεκα | 30 τριάντα | 101 εκατόν ένα |
| 2 δύο / δυο | 12 δώδεκα | 40 σαράντα | 200 διακόσια |
| 3 τρία | 13 δεκατρία | 50 πενήντα | 300 τριακόσια |
| 4 τέσσερα | 14 δεκατέσσερα | 60 εξήντα | 400 τετρακόσια |
| 5 πέντε | 15 δεκαπέντε | 70 εβδομήντα | 500 πεντακόσια |
| 6 έξι | 16 δεκαέξι / δεκάξι | 80 ογδόντα | 600 εξακόσια |
| 7 επτά / εφτά | 17 δεκαεπτά / δεκαεφτά | 90 ενενήντα | 700 επτακόσια / εφτακόσια |
| 8 οκτώ / οχτώ | 18 δεκαοκτώ / δεκαοχτώ | 1.000 χίλια | 800 οκτακόσια / οχτακόσια |
| 9 εννέα / εννιά | 19 δεκαεννέα / δεκαεννιά | 2.000 δύο χιλιάδες | 900 εννιακόσια |

- **Four numbers agree with the noun**: **ένας/μία/ένα** (ένας φίλος, μία φίλη, ένα βιβλίο), **τρεις/τρία** (τρεις φίλοι, τρεις φίλες, τρία βιβλία; gen. τριών), **τέσσερις/τέσσερα** (τέσσερις μέρες; gen. τεσσάρων), and the hundreds from 200 (**διακόσιοι άντρες, διακόσιες γυναίκες, διακόσια παιδιά**), as do **χίλιοι, χίλιες, χίλια**.
- The same applies inside bigger numbers: **είκοσι μία γυναίκες, τριάντα τρεις μέρες**.
- **Χιλιάδα** is a feminine noun: **δύο χιλιάδες, τρεις χιλιάδες, διακόσιες χιλιάδες**. **Εκατομμύριο, δισεκατομμύριο** are neuter nouns: **δύο εκατομμύρια ευρώ**.
- **Εκατό** before another number becomes **εκατόν**: **εκατόν πενήντα**.
- Decimal comma, thousands point: **2.500,75 €** "δύο χιλιάδες πεντακόσια ευρώ και εβδομήντα πέντε λεπτά".

# time-dates | A2 | Ώρα, ημερομηνίες, τακτικά | Time, dates and ordinals

| Ordinal | | | |
|-|-|-|-|
| 1st πρώτος | 4th τέταρτος | 7th έβδομος | 10th δέκατος |
| 2nd δεύτερος | 5th πέμπτος | 8th όγδοος | 20th εικοστός |
| 3rd τρίτος | 6th έκτος | 9th ένατος | 100th εκατοστός |

| Time | Greek |
|-|-|
| What time is it? | Τι ώρα είναι; |
| It's one o'clock. | Είναι μία. |
| 3:00 / at 3:00 | τρεις / στις τρεις |
| 2:30 | δύο και μισή |
| 4:15 | τέσσερις και τέταρτο |
| 4:45 | πέντε παρά τέταρτο |
| 6:10 / 6:50 | έξι και δέκα / εφτά παρά δέκα |
| at 1:00 | στη μία |

- Hours are **feminine** (η ώρα): **στις τρεις, στις τέσσερις, στη μία**.
- **Dates**: the cardinal for every day except the 1st: **η πρώτη Μαΐου**, but **στις 25 Μαρτίου** (είκοσι πέντε), **στις 3 Αυγούστου**. The month is in the **genitive**.
- **Years**: **το 1821** "χίλια οκτακόσια είκοσι ένα", **το 2026** "δύο χιλιάδες είκοσι έξι", **τον 19ο αιώνα** "τον δέκατο ένατο αιώνα".
- **Age**: **Είμαι τριάντα χρονών** / **Είμαι τριάντα (ετών)**; **Πόσων χρονών είσαι;**
- **Days**: **τη Δευτέρα, την Τρίτη, την Τετάρτη, την Πέμπτη, την Παρασκευή, το Σάββατο, την Κυριακή**.
