# Brief: lexicon entries for the next most frequent Modern Greek lemmas (10k extension)

Do NOT call any mcp__hearthbot__ tools. Do not write anything under /mnt/project-files. Do not install packages. Do not run git. Write only the output file you are given. Do the linguistic work yourself (you are a fluent Greek lexicographer); a script may only write/validate JSON you composed.

Input: a JSON array of candidates `{lemma, rank, corpus_forms, wikt_pos, wikt_gloss, wikt_forms}`. They are the most frequent Greek lemmas (wordfreq Greek list: Wikipedia, subtitles, news, web) that our lexicon lacks. Lemmas came from Wiktionary via automatic matching, so a few are wrong: a learned/katharevousa variant where the corpus forms really belong to a common word, an inflected form, a capitalised name, an abbreviation. `corpus_forms` are the real corpus spellings behind the candidate; `wikt_forms` = how many inflected forms Wiktionary has for this lemma (we take the inflection table from there).
Also read the known-lemma file (path given): a JSON object `{lemma: short gloss}` of the 8,214 words already in the lexicon.

For each candidate, in order:
1. Decide the true dictionary lemma (verbs present 1sg, nouns nom sg (nom pl if plural-only), adjectives masc nom sg; monotonic accents; standard spelling).
2. SKIP (write `{"i": <index in input>, "skip": "<reason>"}`) if: the lemma is already in the known file (also check accent and -άω/-ώ variants); it is a proper name, ethnonym-as-name, abbreviation, foreign word not used in Greek, a fragment (απ, γι, κα), a typo; or a slur. Obscene but very common words (e.g. πίπα in its vulgar sense) may be entered with an honest gloss and "register": "vulgar". Plain interjections that learners hear constantly (αχ, ρε, μπα) are worth entering as pos "other".
   Distinct words that differ only by accent are different lemmas (που relative "that, which, where" vs known πού "where?"; πως "that" vs πώς "how?"; πάρα "very (πάρα πολύ)" vs παρά). Enter them.
   Adverbs in -α/-ως from an adjective (κύρια, αγωνιστικά) are worth entering only if the adjective is known or entered too AND the adverb has its own frequent use; otherwise skip as "adverb of X".
3. If two candidates in your batch are the same lemma, write one entry (on the first) and skip the other with reason "dup of <lemma>".
4. Otherwise write a full entry.

Entry format (match exactly; omit sub-objects that do not apply):
```
{
 "i": 17,
 "lemma": "διορίζω",

 "cefr_est": "B2",

}
```
Field rules (same conventions as the existing lexicon):
- translit: η/ι/υ/ει/οι→i, ω/ο→o, αι→e, ου→ou, β→v, γ→g, δ→d, θ→th, ξ→ks, φ→f, χ→ch, ψ→ps, αυ/ευ→av/ev before voiced sounds and vowels, af/ef before voiceless, μπ→b initially else mb, ντ→d initially else nd, γκ→g initially else ng. No accents. (It is regenerated by script; a close attempt is fine.)
- pos: noun, verb, adjective, adverb, pronoun, preposition, conjunction, particle, numeral, article, other. pos_raw: Noun, Verb, Adj, Adv, Pron, Prep, Conj, Part, Num, Phr, Interj.
- gloss: short English, semicolon-separated senses, most common first; verbs start with "to ". Give the sense that makes the word frequent (σύνοδος = summit; synod; νομός = prefecture; δίκη = trial; lawsuit). Add "register": "formal" / "colloquial" / "vulgar" / "dated" only when it matters to a learner.
- example: ONE natural sentence, 5-12 words, written by you, using the word (any inflected form) in the kind of context where Greeks actually say or read it today (conversation, news, everyday life). Vary sentence shapes; never "This is a X." The English must be an idiomatic translation of exactly that sentence. Check gender/case agreement of every article and adjective in your sentence.
- verb: present_1sg; aorist_1sg (simple past; for deponents the commonly used aorist, e.g. κοιμάμαι→κοιμήθηκα, ανέρχομαι→ανήλθα; null if none in use); aorist_passive_1sg only for active verbs with a commonly used passive; participle (-μένος) only if in common use; conj_group "A" (γράφω), "B1" (αγαπώ/-άω), "B2" (θεωρώ), "deponent", "irregular".
- Nouns: "form_key": "Gen: δίκης | f (1st decl)", "noun": {"gen_sg": "δίκης", "gender": "f", "declension": 1, "model": "f-η-ες"}. declension 1 = fem -α/-η(-ες), masc -ας/-ης; 2 = -ος/-ο, neuter -ι/-ί; 3 = neuter -μα, -ος (neut), fem -η/-ση with -εις, -ως/-ον neuters. gender m/f/n/common. "pl_only": true for plural-only nouns.
  model, choose from: m-ας-a (γείτονας; αγώνας), m-ας-b (τουρίστας, άντρας, μήνας: gen.pl -ών), m-ης (εργάτης), m-ος-fixed (οδηγός, γάμος), m-ος-antepenult-a (άνθρωπος→ανθρώπου), m-ος-antepenult-b (καλόγερος→καλόγερου), m-έας (κουρέας), m-imparisyllabic-final (γαλατάς), m-imparisyllabic-penult (μανάβης), m-imparisyllabic-antepenult (φούρναρης), f-α-a (ελπίδα, εβδομάδα, εικόνα, μητέρα: gen.pl on the PENULT), f-α-b (θάλασσα, αξία, γυναίκα, ώρα, καρδιά; all -ία/-εια/-ιά/-τρια/-ισσα: gen.pl on the FINAL), f-η-ες (τέχνη, αγάπη), f-ος (μέθοδος), f-η-εις (κυβέρνηση, πόλη), f-imparisyllabic-ά (γιαγιά), f-imparisyllabic-ού (αλεπού), f-ω-b (ηχώ), common-ής-είς (συγγενής), n-ο-a (θέατρο, βουνό, βιβλίο), n-ο-b (σύννεφο→σύννεφου), n-ί (παιδί), n-ι (αγόρι), n-ος-2syl (κράτος), n-ος-3syl (έδαφος), n-μα (αποτέλεσμα), n-ιμο (πλύσιμο), n-ας (κρέας), n-ως (φως, γεγονός), n-ον (ενδιαφέρον), indecl (loanwords; gen_sg = nom), irregular.
- Adjectives: "form_key": "f: ανδρική, n: ανδρικό" ("m/f: …" only for two-termination adjectives where m = f), "adjective": {"m": "ανδρικός", "f": "ανδρική", "n": "ανδρικό", "model": "adj-ος-η-ο"}. models: adj-ος-η-ο, adj-ος-α-ο (ωραίος), adj-ος-ια-ο (γλυκός), adj-ύς-ιά-ύ (βαρύς), adj-ύς-εία-ύ (ταχύς, learned), adj-ής-ιά-ί, adj-ής-ές-fixed (πολυτελής, ακριβής), adj-ης-ες-shift (συνήθης), adj-ης-α-ικο, adj-άς-ού-άδικο, adj-ων-ουσα-ον, indecl, irregular (two-ending etc.).
- Indeclinables: "form_key": "indecl".
- cefr_est: A1, A2, B1, B2, C1 (level at which a learner normally meets it). Most words here are B1-C1.
- themes: only if the word clearly belongs to a B2 exam topic: work, society, environment, technology, health, education, culture. Otherwise omit.
- forms: null when you kept the input lemma and wikt_forms >= 3 (we take Wiktionary's table). Otherwise (you changed the lemma, or wikt_forms < 3) give EVERY inflected written form: nouns all cases sg+pl; adjectives all genders/cases/numbers; verbs present, imperfect, aorist, perfective subjunctive, imperatives, gerund, and the passive set if used; indeclinables just [lemma].
- needs_review: true only if a form is genuinely uncertain (then set that form to null).

Output: a JSON array, one object per input candidate (entry or skip), in input order, each with "i" (0-based index into the input array). Write it UTF-8 with ensure_ascii False to the output path, validate with python3 that it parses and that every i from 0 to len(input)-1 appears exactly once. Report in at most three lines: entries written, skipped (top reasons), needs_review.
